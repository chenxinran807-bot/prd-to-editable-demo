# 能力策略

核心能力随包提供：语义需求建模、交互设计、通用视觉约束、可编辑运行时和质量验收。核心流程不依赖宿主另行安装任何同类 Agent Skill。

外部能力只有在运行时真实发现、调用并取得结果证据后才能记为 enhancement；名称出现、提示词提及或命令指定都不代表能力存在。缺少外部增强时继续使用随包核心能力，准出标准不降低。

专业模式必须使用 Inspire。系统自动处理可安装组件、能力发现、版本解析、重试和候选修订。只有登录、授权、受限素材访问和会推翻核心方案的选择需要用户操作。

缺少 Inspire 权限时暂停专业交付并保存可恢复状态；不得静默交付低质量替代品。快速评审模式可以输出本地可交互版本，但必须明确其不是专业正式终态。

专业模式的正常成功终态是三个共享同一需求验收合同的 Inspire 候选，而不是交接包、命令说明或本地占位页。候选选定后，未选资产不能进入后续迭代谱系。
