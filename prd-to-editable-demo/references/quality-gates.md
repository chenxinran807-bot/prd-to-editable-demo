# 质量验收协议

## 确定性门禁

- 业务覆盖：需求模型中的核心对象、动作、规则和状态都有可定位的页面或交互证据。
- 路径可达：主流程从入口到结果可走通；异常、取消、重试和返回路径在适用时可用。
- 状态覆盖：声明的加载、空、错误、禁用、权限和结果状态真实呈现，不只存在于文本说明。
- 可编辑性：文字、颜色、图片、Icon、位置、大小、显隐、状态和跳转按交付承诺可修改，并支持撤销。
- 素材来源：Icon、图片和品牌素材有来源或明确待替换标记；Emoji 和文字假 Icon 为 0。
- Inspire 证据：专业模式实际 opened 与 activated 的业务设计 Skill 必须与预检来源、版本和 package hash 一致。

任一确定性门禁失败时，候选保持 `review-required`，不得覆盖上一已接受版本。

## 主观视觉审查

自动规则通过不等于设计优秀。还必须判断：

- 视觉层级是否让用户第一眼理解当前任务和下一步。
- 交互是否符合目标平台原生习惯，而不是桌面模板或通用 AI 页面。
- 业务对象、文案、图片和 Icon 是否语义准确且具有真实演示价值。
- 页面密度、节奏、留白和素材质量是否达到可评审标准。

主观验收结论必须附截图或可定位的原型证据；未完成时不得宣称达到专业基线。
