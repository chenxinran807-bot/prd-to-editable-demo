# Douyin Mall Native Design

生成前读取 `design-tokens.json`、`components.md`、`negative-rules.md` 和 `references.json`。优先复用已定义的移动组件和正式 SVG，不得用字符或表情图形代替 Icon。

## 输出原则

1. 画布宽度以 390px 移动端为基准，同时支持窄屏适配。
2. 页面直接呈现 App 内容，不在页面内部绘制手机外壳。
3. 顶部导航、底部导航、商品卡、弹窗和底部浮层必须使用对应组件规则。
4. 主流程、处理中、成功、失败和回流状态使用一致的组件与反馈语言。
5. 图片使用业务素材或明确的中性占位，不生成虚假品牌 Logo。
6. 所有 Icon 使用 `icons/` 中的 SVG 或业务提供且可追溯的正式资产。
7. 生成结果必须通过 `negative-rules.md` 中的全部阻断规则。

## 视觉语气

整体应轻、清晰、内容优先。信息密度接近成熟商城 App，避免网页后台感和通用 AI 营销页风格。强调色只用于主操作、价格和关键状态，不用大面积装饰性渐变。
