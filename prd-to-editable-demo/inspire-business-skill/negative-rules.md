# Blocking negative rules

以下任一情况出现即阻断交付：

1. 出现 Unicode Emoji 或以普通文字字符冒充 Icon。
2. 使用无来源 Logo、品牌图、人物图或商品图。
3. 使用大面积紫色、蓝紫色或彩虹渐变作为默认视觉风格。
4. 出现桌面侧栏、浏览器工具栏、后台数据看板或页面内手机外壳。
5. 关键按钮只写“继续”“确认操作”等无法追溯业务含义的文案。
6. 触控目标小于 44px，或只靠颜色表达状态。
7. 商品卡、底部导航、弹窗和底部浮层各自使用不一致的圆角与字体体系。
8. 缺少 PRD 已声明的处理中、失败、删除、重试或返回路径。
9. 为了视觉丰富添加 PRD 不存在的营销标签、权益、价格或品牌承诺。
10. 将外部 HTML 编辑工具栏显示在默认评审画面中。
